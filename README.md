# FitTogether

**Project Title:** FitTogether: A Social Fitness Application for Encouraging Physical Activity Through Friendly Competition

**Module:** COMP3000 Final-Year Project

**Programme:** BSc Computer Science (Software Engineering)

**Project Supervisor:** Hai-van Dang

## Project Vision

FitTogether is a mobile fitness application designed to encourage physical activity through step tracking, social interaction and friendly competition among friends and family.

The application aims to address the difficulties individuals may experience when maintaining motivation and comparing their activity levels with others.

A key feature of FitTogether is its **fair-competition leaderboard**, which allows users to compare their progress based on the percentage of their individual daily step goals achieved, rather than solely comparing total steps.

This aims to provide a more inclusive and motivating experience for users with different activity levels.

## Planned Features

- User registration and login
- Daily step tracking
- Personal step goals
- Friends and family connections
- Standard step leaderboard
- Fair-competition leaderboard
- Motivational notifications
- Basic activity history

## Technologies

- Flutter and Dart
- Firebase Authentication
- Cloud Firestore
- Android Health Connect

## Project Status

Currently in development. The Flutter application includes prototype fitness dashboards, friend displays and leaderboards, alongside Firebase Authentication.

The application currently uses simulated step data. Real step tracking, persistent user profiles and friend connections are planned for later development.
